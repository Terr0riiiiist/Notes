#### 定义方法是程序中的独立功能，也是最小的执行单元
#### 使用场景：经常使用的代码打包，放在方法中
**方法可以提高程序的复用性，可维护性**
```
public static 返回值类型 方法名(参数1，参数2...){
	方法体;
	return 返回值;
}
```
**接收数据 -> 计算数据 ->返回数据**

**调用方法时小括号里的参数叫做实际参数，简称*实参*
定义方法时小括号里的参数叫做形式参数，简称*形参*

**return功能： 
- 结束方法
- 将结果返回给调用处

**没有返回值的，返回值类型填void

#### 注意：
1.方法与方法之间是平级关系，不能互相嵌套
2.方法不会主动运行，需要调用
3.小括号中参数需要一一对应（个数，类型）
4.调用方法优先调用实参和形参一一对应的；
