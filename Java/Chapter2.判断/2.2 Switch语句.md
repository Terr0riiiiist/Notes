***switch  ( 表达式)  {*
	*case 1:*
		*statement 1;*
		*break*
	*case 2:*
		*statement 2;*
		*break*
		*...*
	*default*
		*statement n;*
		*break*
*}*


### 流程：1.计算表达式的值 2.依次与case比较 3.如果所有case值都不符合，执行default,然后结束switch 语句

### 表达式可以是：字符/**整数**int byte short/枚举/字符串
### 被匹配的值只能是常量，不能是变量
### 匹配值不能重复

### default语句可以省略；若没有case匹配值，不执行语句
### default与case顺序没有分别；为了可读性一般将default放在case后
### 正常情况下执行匹配case对应的语句，遇到break结束；如果没有break,则会继续执行下一个case的语句，直到遇到break
### case穿透可以用在case 判断重叠时简化代码

*1.case 后可以用箭头 -> 执行语句*
*2.case 匹配值可以填多个值*
*3.switch可以有结果以及yield关键字*
