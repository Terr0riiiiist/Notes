- 声明局部变量 Student stu = new Student(), Student stu加载进栈内存
- 堆中开辟空间 (new Student   -> string name = null, int age = 0, 成员方法的地址) 
- 默认初始化  （String name = null, int age = 0)
- 显示初始化 （如果在Javabean中直接赋值）

- 赋值地址值

**调用方法 ： 栈内存中读取对象的内存地址   ----->在堆内存中对应的内存地址找到成员方法的地址   ----> 读取方法区中的对应地址的方法



### Student stu = new Student();创建对象的七步：

① 加载class字节码文件

② 声明等号左边的局部变量

③ 在堆里面开辟一个空间（对象）

④ 给对象中的属性进行默认初始化

⑤ 给对象中的属性进行显式初始化 （例如 private int age = 18;)

⑥ 给对象中的属性利用构造方法进行初始化

⑦ 把对象的内存地址赋值给等号左边的变量

##### 方法出栈之后，方法里面的变量全部消失

##### 如果没有任何地方使用堆里面的对象，那么对象也会从堆里面消失
