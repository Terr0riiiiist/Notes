# 高级特性

> 来源：[廖雪峰 Python教程 - 高级特性](https://liaoxuefeng.com/books/python/advanced/)

## 为什么需要高级特性

掌握了 Python 的数据类型、语句和函数，基本上就可以编写出很多有用的程序了。

比如构造一个 `1, 3, 5, 7, ..., 99` 的列表，可以通过循环实现：

```python
L = []
n = 1
while n <= 99:
    L.append(n)
    n = n + 2
```

取 list 的前一半元素，也可以通过循环实现。

## 核心思想

在 Python 中：

- 代码不是越多越好，而是越少越好
- 代码不是越复杂越好，而是越简单越好
- **1 行代码能实现的功能，决不写 5 行代码**

基于这一思想，本节介绍 Python 中非常有用的高级特性。请始终牢记：代码越少，开发效率越高。

## 小结

| 特性 | 解决的问题 | 典型写法 |
|------|-----------|---------|
| 切片 | 取一段连续元素 | `L[1:3]` |
| 迭代 | 遍历任意可迭代对象 | `for x in d.items()` |
| 列表生成式 | 一行生成 list | `[x * x for x in range(10)]` |
| 生成器 | 惰性计算，省内存 | `(x * x for x in range(10))` |
| 迭代器 | 按需返回下一个值 | `next(it)` |
