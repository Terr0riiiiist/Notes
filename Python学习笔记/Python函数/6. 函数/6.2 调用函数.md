# 调用函数

> 来源：[廖雪峰 Python教程 - 调用函数](https://liaoxuefeng.com/books/python/function/call-function/index.html)

## 调用内置函数

调用函数需要知道**函数名**和**参数**。查看帮助：

- 官方文档：http://docs.python.org/3/library/functions.html
- 交互命令行：`help(abs)`

```python
>>> abs(100)
100
>>> abs(-20)
20
>>> abs(12.34)
12.34
```

### 参数数量错误 → TypeError

```python
>>> abs(1, 2)
TypeError: abs() takes exactly one argument (2 given)
```

### 参数类型错误 → TypeError

```python
>>> abs('a')
TypeError: bad operand type for abs(): 'str'
```

`max()` 可接收任意多个参数，返回最大的那个：

```python
>>> max(1, 2)
2
>>> max(2, 3, 1, -5)
3
```

## 数据类型转换

| 函数 | 作用 | 示例 |
|------|------|------|
| `int()` | 转为整数 | `int('123')` → `123`，`int(12.34)` → `12` |
| `float()` | 转为浮点数 | `float('12.34')` → `12.34` |
| `str()` | 转为字符串 | `str(1.23)` → `'1.23'`，`str(100)` → `'100'` |
| `bool()` | 转为布尔值 | `bool(1)` → `True`，`bool('')` → `False` |

## 函数名是对象引用

函数名本身就是指向函数对象的引用，可以赋给变量，相当于起"别名"：

```python
>>> a = abs   # 变量a指向abs函数
>>> a(-1)     # 通过a也能调用abs函数
1
```

## 小结

- 调用函数要传入正确的参数（数量、类型都要对）
- 出错时**学会看错误信息**，英文很重要
