# 定义函数

> 来源：[廖雪峰 Python教程 - 定义函数](https://liaoxuefeng.com/books/python/function/define-function/index.html)

## def 语句

定义函数：`def` 语句 + 函数名 + 括号中的参数 + 冒号 `:`，函数体写在缩进块中，用 `return` 返回结果。

```python
def my_abs(x):
    if x >= 0:
        return x
    else:
        return -x

print(my_abs(-99))    # 99
```

- 一旦执行到 `return`，函数就执行完毕并返回结果
- 没有 `return` 语句时，函数也会返回结果，只是结果为 `None`
- `return None` 可简写为 `return`

### 交互环境与文件导入

- 交互环境定义函数时提示符是 `...`，定义结束按**两次回车**回到 `>>>`
- 函数保存在 `abstest.py` 中时，用 `from abstest import my_abs` 导入（`abstest` 是不含 `.py` 的文件名）

## 空函数

用 `pass` 定义什么都不做的函数，作为**占位符**让代码先跑起来：

```python
def nop():
    pass
```

`pass` 也可用在其他语句里，缺少它会语法错误：

```python
if age >= 18:
    pass
```

## 参数检查

- **参数个数不对**：Python 解释器自动抛 `TypeError`
- **参数类型不对**：解释器无法自动检查，需要自己用 `isinstance()` 检查

```python
def my_abs(x):
    if not isinstance(x, (int, float)):
        raise TypeError('bad operand type')
    if x >= 0:
        return x
    else:
        return -x
```

```python
>>> my_abs('A')
TypeError: bad operand type
```

## 返回多个值

语法上可以返回"多个值"，实际是返回一个 **tuple**（括号可省略）：

```python
import math

def move(x, y, step, angle=0):
    nx = x + step * math.cos(angle)
    ny = y - step * math.sin(angle)
    return nx, ny
```

```python
>>> x, y = move(100, 100, 60, math.pi / 6)
>>> print(x, y)
151.96152422706632 70.0
>>> r = move(100, 100, 60, math.pi / 6)
>>> print(r)            # 其实是一个tuple
(151.96152422706632, 70.0)
```

多个变量接收一个 tuple，按位置赋值，写起来方便。

## 小结

- 定义函数需确定函数名和参数个数
- 有必要时先用 `isinstance()` 对参数类型做检查
- 函数体内可用 `return` 随时返回结果
- 没有 `return` 时自动返回 `None`
- "返回多个值"实际是返回一个 tuple
