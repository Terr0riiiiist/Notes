# 条件判断

> 来源：[廖雪峰 Python教程 - 条件判断](https://liaoxuefeng.com/books/python/basic/if/index.html)

## if 语句

计算机能做自动化任务，因为它可以自己做条件判断。

### 基本形式

```python
age = 20
if age >= 18:
    print('adult')
elif age >= 6:
    print('teenager')
else:
    print('kid')
```

完整形式：

```python
if <条件判断1>:
    <执行1>
elif <条件判断2>:
    <执行2>
elif <条件判断3>:
    <执行3>
else:
    <执行4>
```

### 执行特点

- **从上往下判断**，某个判断为 `True` 时执行对应语句，**忽略后续所有 elif 和 else**
- 不要少写冒号 `:`
- `elif` 是 `else if` 的缩写，可有多个

### 简写

```python
if x:
    print('True')
```

- `x` 为非零数值、非空字符串、非空 list 等 → 判断为 `True`
- 否则为 `False`

## input() 的类型问题

`input()` 返回的数据类型是 `str`，不能直接和整数比较。

```python
# 错误写法
birth = input('birth: ')
if birth < 2000:    # TypeError: str 不能和 int 比较
    print('00前')

# 正确写法
s = input('birth: ')
birth = int(s)      # 先转换为整数
if birth < 2000:
    print('00前')
else:
    print('00后')
```

- `int()` 发现字符串不是合法数字时会报 `ValueError`
- 错误处理在后续"错误和调试"章节讲解

## 小结

- `if...elif...else` 从上向下匹配，满足条件时执行对应块，后续不再执行
- `input()` 返回 str，需用 `int()` 转换后才能与数值比较
