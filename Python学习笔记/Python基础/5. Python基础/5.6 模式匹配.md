# 模式匹配

> 来源：[廖雪峰 Python教程 - 模式匹配](https://liaoxuefeng.com/books/python/basic/match/index.html)

## match 语句

当 `if...elif...else` 链过长时，可读性差。`match` 语句可针对某个变量匹配多种情况。

### 基本用法

```python
score = 'B'

match score:
    case 'A':
        print('score is A.')
    case 'B':
        print('score is B.')
    case 'C':
        print('score is C.')
    case _:          # _ 匹配其他任何情况（仅能放在最后）
        print('score is ???.')
```

- 依次用 `case xxx` 匹配
- `case _` 表示"任意值"，只能放在最后
- 比 `if...elif...else` 更易读

## 复杂匹配

### 条件匹配 + 变量绑定

```python
age = 15

match age:
    case x if x < 10:           # 条件匹配，值绑定到变量 x
        print(f'< 10 years old: {x}')
    case 10:                     # 精确匹配单个值
        print('10 years old.')
    case 11 | 12 | 13 | 14 | 15 | 16 | 17 | 18:  # 匹配多个值，| 分隔
        print('11~18 years old.')
    case 19:
        print('19 years old.')
    case _:
        print('not sure.')
```

| 匹配模式 | 语法 | 说明 |
|----------|------|------|
| 条件匹配 | `case x if x < 10` | 满足条件时匹配，值绑定到 x |
| 精确匹配 | `case 10` | 匹配单个值 |
| 多值匹配 | `case 11 \| 12 \| 13` | 用 `\|` 分隔多个值 |
| 通配匹配 | `case _` | 匹配任意值 |

## 匹配列表

`match` 可以匹配列表结构，功能非常强大。

```python
args = ['gcc', 'hello.c', 'world.c']

match args:
    case ['gcc']:
        print('gcc: missing source file(s).')
    case ['gcc', file1, *files]:
        print('gcc compile: ' + file1 + ', ' + ', '.join(files))
    case ['clean']:
        print('clean')
    case _:
        print('invalid command.')
```

| case 模式 | 匹配说明 |
|-----------|----------|
| `['gcc']` | 列表仅有一个元素 `'gcc'` |
| `['gcc', file1, *files]` | 第一个为 `'gcc'`，第二个绑定到 `file1`，其余绑定到 `*files` |
| `['clean']` | 列表仅有一个元素 `'clean'` |
| `_` | 其他所有情况 |

- `*files` 语法：表示任意个剩余元素（可变参数，在函数参数章节详解）

## 小结

- `match` 语句用于替代冗长的 `if...elif...else` 链
- 支持：单值匹配、多值匹配（`|`）、条件匹配（`if`）、变量绑定、列表结构匹配
- `case _` 只能放在最后，表示通配
- 匹配规则灵活，可写出非常简洁的代码
