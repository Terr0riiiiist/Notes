# 数据类型和变量

> 来源：[廖雪峰 Python教程 - 数据类型和变量](https://liaoxuefeng.com/books/python/basic/data-types/index.html)

## 数据类型

Python 能直接处理的数据类型：整数、浮点数、字符串、布尔值、空值。

### 整数

- 可处理任意大小的整数（无大小限制）
- 十六进制用 `0x` 前缀：`0xff00`
- 大数字可用 `_` 分隔：`10_000_000_000` 等同 `10000000000`

### 浮点数

- 即小数，可用科学计数法：`1.23e9`、`1.2e-5`
- 浮点数运算可能有四舍五入误差
- 浮点数无大小限制，超出范围表示为 `inf`

### 字符串

- 用单引号 `'` 或双引号 `"` 括起来
- 转义字符 `\`：`\n` 换行、`\t` 制表符、`\\` 表示 `\`
- `r''` 表示内部字符串默认不转义
- `'''...'''` 表示多行字符串

```python
print('''line1
line2
line3''')
```

### 布尔值

- 只有 `True` 和 `False`（注意大小写）
- 运算符：`and`（与）、`or`（或）、`not`（非）

```python
>>> True and True
True
>>> 5 > 3 or 1 > 3
True
>>> not True
False
```

### 空值

- 用 `None` 表示，不是 `0`

## 变量

- 变量名：大小写英文、数字、`_` 组合，不能用数字开头
- `=` 是赋值语句，同一变量可反复赋值且类型可变（**动态语言**）

```python
a = 123     # a 是整数
a = 'ABC'   # a 变为字符串
```

### 变量在内存中的表示

```python
a = 'ABC'
b = a       # b 指向 a 所指向的数据
a = 'XYZ'   # a 指向新字符串，b 仍指向 'ABC'
print(b)    # 输出 'ABC'
```

- 赋值 `a = 'ABC'`：①内存中创建字符串 `'ABC'`；②创建变量 `a` 指向它
- `x = y` 是把 `x` 指向 `y` 所指向的对象，后续对 `y` 的赋值不影响 `x`

## 常量

- 约定用全大写变量名表示常量：`PI = 3.14159265359`
- Python 无机制保证常量不被改变，仅为习惯用法

## 除法

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `/` | 普通除法，结果始终为浮点数 | `10 / 3` → `3.3333`；`9 / 3` → `3.0` |
| `//` | 地板除，只取整数部分 | `10 // 3` → `3` |
| `%` | 取余数 | `10 % 3` → `1` |

整数运算结果永远精确。

## 小结

- Python 支持多种数据类型，任何数据都可视为"对象"
- 变量用来指向数据对象，赋值就是把变量和数据关联
- Python 整数无大小限制，浮点数超出范围为 `inf`
