### Static Array
#### natural solution
- **get_at / set_at / len => O(1)
- **iteration => O(n)
- word RAM (字单元)
- "array": consecutive chunk of memory.
	- array[i] => memory[address(array) + i]
- **memory allocation model**: allocate array of size n in  ${}\theta(n){}$ time
	- Space: O(time)
	- Insert/ Delete : ${}\theta(n){}$
		- Shifting
		- allocation / copying
			- front: shifting
			- last: *static space, ask for new array*
