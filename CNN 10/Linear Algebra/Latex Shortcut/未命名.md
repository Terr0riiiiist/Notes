# Latex Shortcut — obsidian-latex-suite 默认规则速查

> 来源：`obsidian-latex-suite` 的 `src/default_snippets.js`（main 分支）
> 插件文档：https://github.com/artisticat1/obsidian-latex-suite/blob/main/DOCS.md
>
> **规则来源**：本文件整理的是插件**自带**的默认 snippet，不是自定义的。想加自己的，去设置里的 snippets 文件追加即可。

---

## 0. 先看懂 options 标记

不懂这个，后面的字母全是天书。

| 标记        | 含义                         |
| --------- | -------------------------- |
| `A`       | **自动展开**，不需要按 Tab          |
| 无 `A`     | 打完触发词要按 **Tab** 才展开        |
| `m`       | 仅公式内触发（块、行内都算）             |
| `t`       | 仅正文（公式外）触发                 |
| `M` / `n` | 仅块公式 `$$` 内 / 仅行内公式 `$` 内  |
| `r`       | trigger 是正则表达式             |
| `v`       | 选中态片段，**必须先选中文字**          |
| `w`       | 词边界：前后得是 `.` `,` `-` 之类分隔符 |
| `U`       | 撤销时直接回到打触发词之前，不留那个字符       |
| `T`       | 公式的 `\text{}` 内部           |

`priority` 越大越优先匹配（默认 0，负数 = 让位给更长的匹配）。

## 1. 模式切换与公式环境（最常用）

| 触发 | 结果 | 说明 |
|---|---|---|
| `mk` | `$ $` 光标居中 | 正文里直接打 |
| `mk` | `\( \)` | 公式内打 `mk` |
| `dm` | `$$\n…\n$$` | **行首空白处**才触发；列表里自动对齐缩进 |
| `……beg` ⏎ | `\begin{env}\n…\n\end{env}` | 会吃掉前面一个字符 |
| `beg` + Tab | `\begin{env} … \end{env}` | 单行紧凑版 |

## 2. 希腊字母

| 触发 | 结果 | 触发 | 结果 |
|---|---|---|---|
| `@a` | α | `@G` | Γ |
| `@b` | β | `@D` | Δ |
| `@g` | γ | `@T` | Θ |
| `@d` | δ | `@L` | Λ |
| `@e` | ε | `@S` | Σ |
| `:e` | ε（varepsilon 变体） | `@U` | Υ |
| `@z` | ζ | `@O` | Ω |
| `@t` | θ | `:t` | θ（vartheta 变体） |
| `@i` | ι | `@k` | κ |
| `@l` | λ | `@s` | σ |
| `@u` | υ | `@o` | ω |
| `ome` | ω | `Ome` | Ω |

**另外**：直接打 `alpha`、`beta`、`infty`、`times` 等会自动补上反斜杠，不用记 `@` 前缀。

## 3. 上下标与基本运算

| 触发 | 结果 |
|---|---|
| `sr` | `^{2}` |
| `cb` | `^{3}` |
| `rd` | `^{$0}` 自定指数 |
| `_` | `_{$0}` |
| `sts` | `_\text{$0}` 下标套文字 |
| `sq` | `\sqrt{ $0 }` |
| `2rt` … `9rt` | `\sqrt[n]{ $0 }` n 次根 |
| `//` | `\frac{$0}{$1}` |
| `ee` | `e^{ $0 }` |
| `invs` | `^{-1}` 逆元 |
| `pmod` | `\pmod{n}` |
| `xnn` `xii` `xjj` | `x_n` `x_i` `x_j` |
| `yii` `yjj` `ynn` | `y_i` `y_j` `y_n` |
| `xp1` | `x_{n+1}` |

**自动下标**（最省事的一条）：

- `x3` → `x_{3}`
- `\alpha3` → `\alpha_{3}`
- `\leq3` → `\leq 3`（非希腊字母宏，后面自动补空格）
- `x_{3}4` → `x_{34}`（已写下标还能续写）
- `\vec{a}3` → `\vec{a}_{3}`

## 4. 重音符 / 字体

单个字母 + 后缀，或单独打后缀，两种都行。

| 触发 | 结果 |
|---|---|
| `ahat` / `hat` | `\hat{a}` |
| `abar` / `bar` | `\bar{a}` |
| `adot` / `dot` | `\dot{a}` |
| `addot` / `ddot` | `\ddot{a}` |
| `atilde` / `tilde` | `\tilde{a}` |
| `aund` / `und` | `\underline{a}` |
| `avec` / `vec` | `\vec{a}` |
| `a,.` 或 `a\.` | `\mathbf{a}` 向量加粗 |
| `bf` | `\mathbf{$0}` |
| `rm` | `\mathrm{$0}` |
| `\alpha,.` | `\boldsymbol{\alpha}` |
| `cdot` | `\cdot` |

## 5. 符号与关系

| 分类 | 触发 → 结果 |
|---|---|
| 无限 | `ooo` → `\infty` |
| 求和 | `sum` → `\sum`；`\sum` → `\sum_{i=1}^{N}` 带模板 |
| 求积 | `prod` → `\prod`；`\prod` → `\prod_{i=1}^{N}` |
| 极限 | `lim` → `\lim_{n \to \infty}` |
| 微分 | `+-` → `\pm`；`-+` → `\mp`；`...` → `\dots` |
| 乘积 | `xx` → `\times`；`**` / `cdot` → `\cdot` |
| 几何 | `nabl` → `\nabla`；`deg` → `\degree`；`para` → `\parallel` |
| 等价 | `===` → `\equiv`；`simm` → `\sim`；`sim=` → `\simeq`；`prop` → `\propto` |
| 不等式 | `!=` → `\neq`；`>=` → `\geq`；`<=` → `\leq`；`>>` → `\gg`；`<<` → `\ll` |
| 箭头 | `->` → `\to`；`<->` → `\leftrightarrow`；`!>` → `\mapsto`；`=>` → `\implies`；`=<` → `\impliedby` |
| 集合 | `and` → `\cap`；`orr` → `\cup`；`inn` → `\in`；`notin` → `\not\in` |
| 集合（续） | `\\\` → `\setminus`；`sub=` → `\subseteq`；`sup=` → `\supseteq`；`eset` → `\emptyset` |
| 集合字面量 | `set` → `\{ $0 \}` |
| 存在 | 打 `e\xi sts` → `\exists` |
| 函数名 | `exp` `log` `ln` `det` 自动补斜杠并转正体 |
| 三角函数 | `sin` `cos` `tan` `cot` `sec` `csc` 及 `arc*` 自动补斜杠 |
| 反三角 | `arccsc` `arcsec` `arccot` → `\operatorname{...}`（MathJax 无内置） |
| 花体 | `LL` → `\mathcal{L}`；`HH` → `\mathcal{H}` |
| 黑板粗体 | `CC` `RR` `ZZ` `NN` `QQ` → `\mathbb{C/R/Z/N/Q}` |

## 11. 两个后台正则守卫（"怪现象"的来源）

1. **打宏名时禁用 snippet**：在 `\alpha` 里输入 `\alph` 不会再误触发成别的。识别靠插件内置的全量宏表，自己加宏可以 `require("latex-suite").ALL_MACROS.push("\\my_macro")`。
2. **宏后自动补空格**：识别到不完整宏名时自动断词，所以 `\top` 不会变成 `\to` + `p`。

---

## 12. 默认注释掉的可选功能

需要的话去 snippets 文件里取消注释：

- 破折号：`--` → `–`，`—-` → `—`，`—-` → `---`
- 正文中单个字母自动转公式（`a` → `$a$`，排除 `a A I`）
- 正文中的希腊字母自动转公式
- 正文中的 `x=2`、`x=n+1` 自动转公式
- 文本环境：`"` 包起来变 `\text{}`（这个默认是开的）

## 13. 线性代数常用速记（自用）

按线性代数这门课的高频度重新排的，日常够用就行：

| 场景 | 直接打 |
|---|---|
| 行内公式 | `mk` |
| 独立成行的公式 | `dm`（行首） |
| 分数 | `//` |
| 平方 / 立方 / 任意次幂 | `sr` / `cb` / `rd` |
| 下标 / 上标 | `_` / `rd` |
| $n$ 次根 / 平方根 | `2rt`…`9rt` / `sq` |
| 矩阵（含括号形式） | `pmat` `bmat`（`bmat` 小写是方括号、大写 `B` 是花括号） |
| 行列式 | 打 `det` 自动出 |
| 逆矩阵 | `invs` 或自己打 `\bm{A}^{-1}` |
| 转置 | `\bm{A}^{T}`（没有专属快捷键，用 `rd` 更快：`rd` → `^{T}`） |
| 伴随矩阵 | `\bm{A}^{*}`（`conj`） |
| 特征值特征向量 | `\lambda` `kesi`…（希腊字母走自动补斜杠） |
| 向量加粗 | `a,.` 或 `a\.` |
| 内积 / 范数 | `\bm{a}^{T}\bm{b}` / `norm` |
| 区间 | `lr[` → `\left[ \right]` |
| 证明环境的 `\qed` | 没有默认 snippet，需自建 |

> 线性代数没有专属的 `vmatrix`、`bmatrix` 自动模板以外的补充。想要 `\begin{vmatrix}` 得自己往 snippets 文件里加一行。
