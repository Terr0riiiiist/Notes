```C
	void IncreaseSize(SeqList &L, int len){
		int *p = L.data;
		L.data = (int*)malloc(sizeof(int)*(L.Maxsize+len));
		for(i=0; i<L.maxsize; i++){
			L.data[i] = p[i]; //通过遍历把原先的数据一个一个赋给新数组,时间开销大
		}
		L.Maxsize += len;
		free(p);
	} //realloc函数
```

### 顺序表的特性
- **随机访问**, 可以在O(1)内找到第i个元素
- 存储密度高
- 拓展容量不方便
- 插入，删除不方便
