算法时间复杂度
**事前预估**算法时间开销T( n)和问题规模n的关系

$$
T(n) = O(n^k)
$$
- 相加只保留最高阶的项
- 多项相乘都保留

$$
O(1) < O(\log_{2}n) < O(n) 
< O(n\log_{2}n) < O(n^2)< O(n^3 < O(2^n)) < O(n!) < O(n^n)
$$


#### 推论
- 顺序执行的代码只会影响常数项，可忽略
- 只需挑循环中一个基本操作分析它的执行次数与n关系即可
- 如果有多层循环，只需要考虑最深层循环次数即可
- **最坏 / 平均时间复杂度

```C
void func(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 1; j < n; j *= 2) {
            printf("%d %d\n", i, j);
        }
    }
} // n*log2n,
```
时间复杂度${}O(n\log_{2}n){}$

```c
void func(int n) {
    for (int i = 1; i < n; i++) {
        for (int j = 1; j < i; j++) {
            printf("%d %d\n", i, j);
        }
    }
}
```
时间复杂度1+2+3+...+n
${}O(n^2){}$
