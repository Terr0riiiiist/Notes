# 使用list和tuple

> 来源：[廖雪峰 Python教程 - 使用list和tuple](https://liaoxuefeng.com/books/python/basic/list-tuple/index.html)

## list（列表）

- Python 内置有序集合，**可变**
- 用 `[]` 表示，元素用逗号分隔

```python
>>> classmates = ['Michael', 'Bob', 'Tracy']
>>> len(classmates)
3
```

### 索引访问

- 索引从 `0` 开始：`classmates[0]` → `'Michael'`
- 负索引取倒数：`classmates[-1]` → `'Tracy'`
- 索引越界报 `IndexError`

以五个元素的 list `L = ['a', 'b', 'c', 'd', 'e']` 为例，正负索引一一对应：

| 元素   | a  | b  | c  | d  | e  |
| ---- | -- | -- | -- | -- | -- |
| 正索引  | 0  | 1  | 2  | 3  | 4  |
| 负索引  | -5 | -4 | -3 | -2 | -1 |

- 正索引范围：`0 ~ len(L) - 1`
- 负索引范围：`-len(L) ~ -1`
- 换算关系：`L[-i]` 等价于 `L[len(L) - i]`，例如 `L[-1]` = `L[4]`，`L[-5]` = `L[0]`

```python
>>> L = ['a', 'b', 'c', 'd', 'e']
>>> L[0], L[4]
('a', 'e')
>>> L[-5], L[-1]
('a', 'e')
>>> L[5]
Traceback (most recent call last):
IndexError: list index out of range
```

- `L[5]` 和 `L[-6]` 都越界，报 `IndexError`

> 取一段连续元素要用切片 `L[a:b]`，见 [[7.2 切片]]

### 常用操作

| 操作     | 方法             | 示例                             |
| ------ | -------------- | ------------------------------ |
| 追加到末尾  | `append()`     | `classmates.append('Adam')`    |
| 插入指定位置 | `insert(i, x)` | `classmates.insert(1, 'Jack')` |
| 删除末尾   | `pop()`        | `classmates.pop()`             |
| 删除指定位置 | `pop(i)`       | `classmates.pop(1)`            |
| 替换元素   | 直接赋值           | `classmates[1] = 'Sarah'`      |

### 嵌套与多类型

```python
>>> L = ['Apple', 123, True]              # 元素类型可不同
>>> s = ['python', 'java', ['asp', 'php'], 'scheme']  # list 可嵌套
>>> s[2][1]                                # 'php'，二维数组
```

## tuple（元组）

- 有序列表，**一旦初始化不可修改**
- 用 `()` 表示
- 没有 `append()`、`insert()` 等方法
- 比 list 更安全，能用 tuple 就尽量用

```python
>>> classmates = ('Michael', 'Bob', 'Tracy')
```

### 注意事项

1. **单元素 tuple 必须加逗号**：

```python
>>> t = (1,)    # 正确，这是 tuple
>>> t = (1)     # 错误！这是整数 1，不是 tuple
```

2. **空 tuple**：`t = ()`

3. **"可变的" tuple**：

```python
>>> t = ('a', 'b', ['A', 'B'])
>>> t[2][0] = 'X'
>>> t[2][1] = 'Y'
>>> t
('a', 'b', ['X', 'Y'])
```

- tuple 的"不可变"是指**每个元素的指向永远不变**
- tuple 指向一个 list，不能改为指向其他对象，但该 list 本身是可变的
- 要创建内容也不变的 tuple，必须保证每个元素本身也不可变

## 小结

| 特性 | list | tuple |
|------|------|-------|
| 可变性 | 可变 | 不可变 |
| 表示 | `[]` | `()` |
| 方法 | append/insert/pop 等 | 无（仅索引访问） |
| 安全性 | 较低 | 较高 |
| 适用场景 | 需要增删改 | 数据不变的场景 |
