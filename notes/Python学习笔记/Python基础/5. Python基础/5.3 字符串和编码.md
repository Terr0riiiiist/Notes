# 字符串和编码

> 来源：[廖雪峰 Python教程 - 字符串和编码](https://liaoxuefeng.com/books/python/basic/string-encoding/index.html)

## 字符编码

### 编码发展史

| 编码 | 说明 |
|------|------|
| ASCII | 1字节，127个字符（英文字母、数字、符号） |
| GB2312 | 中文编码，2字节表示中文 |
| Unicode | 统一所有语言，通常2字节（UCS-16） |
| UTF-8 | 可变长编码，英文1字节，汉字通常3字节 |

### 编码关系

- ASCII 编码 → Unicode：在前面补0即可
- Unicode → UTF-8：根据字符大小编码为1-6字节
- UTF-8 兼容 ASCII，历史软件可继续工作

### 通用工作方式

- **内存中**：统一使用 Unicode 编码
- **保存/传输时**：转换为 UTF-8 编码

## Python 的字符串

- Python 3 字符串以 **Unicode** 编码，直接支持多语言

### ord() 和 chr()

```python
>>> ord('A')
65
>>> ord('中')
20013
>>> chr(66)
'B'
>>> chr(25991)
'文'
```

### str 与 bytes

- `str`：Unicode 表示，一个字符对应若干字节
- `bytes`：以字节为单位，用 `b` 前缀表示

```python
x = b'ABC'            # bytes 类型
'ABC'.encode('ascii')  # str → bytes
b'ABC'.decode('ascii') # bytes → str
```

- 含中文的 str 用 UTF-8 编码为 bytes
- 含中文的 str 无法用 ASCII 编码（会报 `UnicodeEncodeError`）
- `decode()` 可传 `errors='ignore'` 忽略错误字节

### len() 函数

```python
len('ABC')              # 3（字符数）
len('中文')              # 2（字符数）
len('中文'.encode('utf-8'))  # 6（字节数，每个中文3字节）
```

### 源代码编码声明

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
```

- 第一行：告诉 Linux/macOS 这是 Python 可执行程序
- 第二行：告诉解释器按 UTF-8 读取源代码

## 格式化

### % 方式（C语言风格）

```python
>>> 'Hello, %s' % 'world'
'Hello, world'
>>> 'Hi, %s, you have $%d.' % ('Michael', 1000000)
'Hi, Michael, you have $1000000.'
```

| 占位符 | 替换内容 |
|--------|----------|
| `%d` | 整数 |
| `%f` | 浮点数 |
| `%s` | 字符串 |
| `%x` | 十六进制整数 |

- 指定位数：`'%2d-%02d' % (3, 1)`、`'%.2f' % 3.1415926`
- `%s` 永远起作用，会转换任何类型
- `%%` 转义为普通 `%`

### format() 方法

```python
>>> 'Hello, {0}, 成绩提升了 {1:.1f}%'.format('小明', 17.125)
'Hello, 小明, 成绩提升了 17.1%'
```

### f-string（推荐）

```python
>>> r = 2.5
>>> s = 3.14 * r ** 2
>>> print(f'The area of a circle with radius {r} is {s:.2f}')
The area of a circle with radius 2.5 is 19.62
```

- `{xxx}` 替换为变量值
- `:.2f` 指定保留两位小数

## 小结

- Python 3 字符串使用 Unicode，直接支持多语言
- `str` 和 `bytes` 互转时需指定编码，**始终坚持用 UTF-8**
- 格式化优先用 f-string
