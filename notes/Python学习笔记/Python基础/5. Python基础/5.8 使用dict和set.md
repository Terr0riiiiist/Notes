# 使用dict和set

> 来源：[廖雪峰 Python教程 - 使用dict和set](https://liaoxuefeng.com/books/python/basic/dict-set/index.html)

## dict（字典）

- 全称 dictionary，键值对（key-value）存储，查找速度极快
- 用 `{}` 表示

```python
>>> d = {'Michael': 95, 'Bob': 75, 'Tracy': 85}
>>> d['Michael']
95
```

### 查找原理

类似查字典——通过索引（哈希算法）直接定位到 value 的存储位置，不随数据量增大而变慢。

### 常用操作

| 操作          | 方法                    | 示例                           |
| ----------- | --------------------- | ---------------------------- |
| 通过 key 放入   | 直接赋值                  | `d['Adam'] = 67`             |
| 判断 key 是否存在 | `in`                  | `'Thomas' in d` → `False`    |
| 安全获取        | `get(key[, default])` | `d.get('Thomas', -1)` → `-1` |
| 删除 key      | `pop(key)`            | `d.pop('Bob')` → `75`        |

- key 不存在直接访问会报 `KeyError`
- `get()` 不存在时返回 `None`（交互环境不显示）或指定默认值
- 多次对同一 key 赋值，后面的值覆盖前面的
- dict 内部存放顺序与 key 放入顺序**无关**

### dict vs list

| 特性 | dict | list |
|------|------|------|
| 查找速度 | 极快，不随 key 增多变慢 | 随元素增加而变慢 |
| 内存占用 | 大（空间换时间） | 小 |
| key 要求 | 必须是不可变对象 | 无 |

### key 必须不可变

dict 根据 key 计算存储位置（哈希算法），key 必须不可变。

```python
>>> key = [1, 2, 3]
>>> d[key] = 'a list'
TypeError: unhashable type: 'list'    # list 可变，不能作为 key
```

- 可作为 key：字符串、整数等不可变对象
- 不可作为 key：list 等可变对象

## set

- 一组 key 的集合，**不存储 value**，**无重复元素**
- 创建方式：`{1, 2, 3}` 或 `set([1, 2, 3])`

```python
>>> s = {1, 1, 2, 2, 3, 3}
>>> s
{1, 2, 3}            # 自动去重
```

### 常用操作

| 操作   | 方法            | 示例            |
| ---- | ------------- | ------------- |
| 添加元素 | `add(key)`    | `s.add(4)`    |
| 删除元素 | `remove(key)` | `s.remove(4)` |
| 交集   | `&`           | `s1 & s2`     |
| 并集   | \|            | s1 \| s2      |

```python
>>> s1 = {1, 2, 3}
>>> s2 = {2, 3, 4}
>>> s1 & s2    # {2, 3}
>>> s1 | s2    # {1, 2, 3, 4}
```

- set 原理与 dict 相同，同样不能放入可变对象

## 再议不可变对象

### 可变对象（如 list）

```python
>>> a = ['c', 'b', 'a']
>>> a.sort()
>>> a
['a', 'b', 'c']       # 对象内容被改变
```

### 不可变对象（如 str）

```python
>>> a = 'abc'
>>> a.replace('a', 'A')
'Abc'                  # 返回新字符串
>>> a
'abc'                  # 原对象不变
```

- `a` 是变量，`'abc'` 是字符串对象
- `replace()` 不改变原对象，而是**创建并返回新对象**
- 不可变对象调用任何方法都不会改变自身内容

```
┌───┐     ┌───────┐
│ a │────▶│ 'abc' │  ← 原对象，不变
└───┘     └───────┘
┌───┐     ┌───────┐
│ b │────▶│ 'Abc' │  ← replace() 创建的新对象
└───┘     └───────┘
```

## 小结

- dict：key-value 存储，查找极快，用空间换时间
- set：无重复 key 的集合，支持集合运算（交集、并集）
- dict 和 set 的 key 都必须是**不可变对象**
- 不可变对象调用方法不改变自身，而是返回新对象
