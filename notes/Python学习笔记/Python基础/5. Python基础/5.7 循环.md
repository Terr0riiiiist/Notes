# 循环

> 来源：[廖雪峰 Python教程 - 循环](https://liaoxuefeng.com/books/python/basic/loop/index.html)

## 两种循环

### for...in 循环

依次把 list 或 tuple 中的每个元素迭代出来。

```python
names = ['Michael', 'Bob', 'Tracy']
for name in names:
    print(name)
```

#### range() 函数

生成整数序列，`range(5)` → `0, 1, 2, 3, 4`

```python
# 计算 1-100 整数之和
sum = 0
for x in range(101):
    sum = sum + x
print(sum)    # 5050
```

- `list(range(5))` → `[0, 1, 2, 3, 4]`
- `range(101)` 生成 0-100 的整数序列

##### 三种写法

| 写法 | 生成什么 |
|------|----------|
| `range(stop)` | `0` 到 `stop-1` |
| `range(start, stop)` | `start` 到 `stop-1` |
| `range(start, stop, step)` | 从 `start` 开始，每次加 `step`，到 `stop` 之前停 |

- `start` 可省略，默认 `0`
- `stop` 必须给，而且**永远取不到**（左闭右开）
- `step` 可省略，默认 `1`，可以是负数（倒序）
- 元素个数 = `max(0, ceil((stop - start) / step))`

```python
list(range(5))           # [0, 1, 2, 3, 4]
list(range(1, 6))        # [1, 2, 3, 4, 5]      想包含 6 就写 7
list(range(0, 10, 3))    # [0, 3, 6, 9]
list(range(9, -1, -1))   # [9, 8, 7, 6, 5, 4, 3, 2, 1, 0]
list(range(5, 0))        # []                   start > stop 且 step 为正 → 空
```

只要循环 n 次而不用循环变量时，约定用 `_`：

```python
for _ in range(3):
    print('hello')       # 打印 3 次
```

##### 用 range() 取列表元素

`for x in a:` 直接拿元素，但拿不到下标。需要下标时就配合 `range(len(a))`：

> `range(len(a))` 没有特殊语法，就是普通嵌套调用：`len(a)` 先算出一个整数，再把它交给 `range`。列表有 n 个元素时合法下标是 `0 ~ n-1`，`range(len(a))` 刚好全生成出来，等价于 `range(0, len(a))`。
>
> 注意 `len(a)` 只在循环开始前算一次：循环中往 `a` 里增删元素，循环次数也不会变（`while i < len(a)` 则会每轮重算）。

```python
langs = ['Python', 'Java', 'C++']

# 1. 最基础：用下标取元素
for i in range(len(langs)):
    print(i, langs[i])
# 0 Python
# 1 Java
# 2 C++
```

```python
# 2. 需要下标参与计算
items = ['苹果', '香蕉', '橘子']
for i in range(len(items)):
    print(f'第 {i + 1} 个是 {items[i]}')
# 第 1 个是 苹果 ...
```

```python
# 3. 跳着取：range 的 step 直接控制列表的步长
nums = [10, 20, 30, 40, 50, 60]
for i in range(0, len(nums), 2):
    print(nums[i])          # 10 30 50
```

```python
# 4. 倒序遍历
for i in range(len(nums) - 1, -1, -1):
    print(nums[i])          # 60 50 40 30 20 10
```

```python
# 5. 成对比较相邻元素
data = [3, 1, 4, 1, 5]
for i in range(len(data) - 1):
    if data[i] > data[i + 1]:
        print(f'{data[i]} > {data[i + 1]}')
```

```python
# 6. 分段切片：每 2 个一组
for i in range(0, len(nums), 2):
    print(nums[i:i + 2])    # [10, 20] [30, 40] [50, 60]
```

```python
# 7. 二维列表
matrix = [[1, 2], [3, 4], [5, 6]]
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        print(matrix[i][j], end=' ')    # 1 2 3 4 5 6
```

**必须用下标、不能用 `for x in a:` 的场景**：

```python
# 修改列表自身元素 —— 只能靠下标写回去
scores = [60, 70, 80]
for i in range(len(scores)):
    scores[i] = scores[i] + 5
print(scores)               # [65, 75, 85]

# 这样改不动：x 只是个临时变量
for x in scores:
    x = x + 5               # 列表没变
```

```python
# 倒序删除：正序删会漏元素甚至 IndexError
nums = [1, 2, 3, 4, 5, 6]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 == 0:
        nums.pop(i)
print(nums)                 # [1, 3, 5]
```

```python
# 两个列表长度不同：用较短的长度兜住，防止 IndexError
a = [1, 2, 3, 4]
b = ['x', 'y']
for i in range(min(len(a), len(b))):
    print(a[i], b[i])       # 1 x / 2 y，只跑 2 轮

for i in range(len(a)):     # 按长的走 → 第 3 轮 b[2] 越界
    print(a[i], b[i])       # IndexError
```

`min(len(a), len(b))` 就是取两个长度中较小的那个。`min()` 可以收多个参数，`min(3, 5)` → `3`。

**能用更 Pythonic 写法时别绕 `range`**：

```python
# 只要元素 → 直接迭代
for x in langs:
    print(x)

# 要下标 + 元素 → enumerate
for i, x in enumerate(langs):
    print(i, x)

# 两个列表并排取 → zip（自动在较短的序列处停下，等于 range(min(len, len)) 的自动版）
names = ['Alice', 'Bob']
ages = [18, 20]
for name, age in zip(names, ages):
    print(name, age)

# 还要下标就套一层 enumerate
for i, (name, age) in enumerate(zip(names, ages)):
    print(i, name, age)
```

##### range 不是 list

`print(range(5))` 输出的是 `range(0, 5)`，不是 `[0, 1, 2, 3, 4]`。

它是一个**惰性序列对象**：不一次性把数字都造出来，只在迭代时逐个产生，所以很省内存。想看内容就套一层 `list()`。

它同样支持 `len()`、`in`、索引和切片：

```python
len(range(5))            # 5
3 in range(5)            # True
list(range(10)[2:5])     # [2, 3, 4]
```

##### 几个容易踩的坑

1. **参数必须是整数**。`range(1.5)` 直接报 `TypeError`，要小数得用 `numpy.arange()` 或自己乘除。
2. **`step=0` 报错**，抛 `ValueError: range() arg 3 must not be zero`，不是死循环。
3. **别在正序遍历时删元素**。`for i in range(len(a)): a.pop(i)` 会漏掉元素，要么倒序 `for i in range(len(a)-1, -1, -1)`，要么用列表推导式重建。
4. **只遍历元素时不用绕索引**。`for x in a:` 比 `for i in range(len(a)): x = a[i]` 更短也更快；要同时拿索引和值就用 `for i, x in enumerate(a):`。
5. **循环变量会残留**。Python 没有块作用域，`for i in range(3)` 结束后 `i` 仍然等于 `2`。
6. **别用 `sum`、`list`、`max` 这些内置名当变量名**，会把内置函数覆盖掉，换成 `total`、`nums` 更安全。

### while 循环

只要条件满足就不断循环，不满足时退出。

```python
# 计算 100 以内所有奇数之和
sum = 0
n = 99
while n > 0:
    sum = sum + n
    n = n - 2
print(sum)    # 2500
```

## break

提前退出循环。

```python
n = 1
while n <= 100:
    if n > 10:
        break       # n=11 时退出循环
    print(n)
    n = n + 1
print('END')        # 打印 1~10 后输出 END
```

## continue

跳过当前这次循环，直接开始下一次循环。

```python
# 只打印奇数
n = 0
while n < 10:
    n = n + 1
    if n % 2 == 0:
        continue    # 偶数时跳过，不执行后续 print
    print(n)        # 输出 1, 3, 5, 7, 9
```

## for...else

`for` 循环可以带一个 `else` 分支，含义是**"循环没有被 `break` 打断"**：

```python
for n in range(2, 10):
    if n == 5:
        break
    print(n)
else:
    print('正常跑完')     # 被 break 中断了，这里不会执行
```

- 循环体执行 **0 次**也算正常结束，`else` 会执行
- 主要用来写"没找到"的场景：找到就 `break`，`else` 里处理没找到
- `while` 也支持 `else`，规则一样

## 小结

| 语句 | 作用 |
|------|------|
| `break` | 提前结束整个循环 |
| `continue` | 提前结束本轮循环，开始下一轮 |
| `for...else` | 循环没被 `break` 打断时执行 |

- `range` 三种写法：`range(stop)` / `range(start, stop)` / `range(start, stop, step)`，`stop` 永远取不到
- `step` 为负可以倒序；`step=0` 报 `ValueError`；参数只能是整数
- `range` 是惰性对象不是 list，`print(range(5))` 显示 `range(0, 5)`
- `break` 和 `continue` 通常**必须配合 `if` 使用**
- **不要滥用**：大多数循环可通过改写条件或逻辑去掉它们
- 滥用会造成代码逻辑分叉过多，容易出错
- 死循环可用 `Ctrl+C` 退出
