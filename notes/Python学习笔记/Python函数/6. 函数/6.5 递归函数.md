# 递归函数

> 来源：[廖雪峰 Python教程 - 递归函数](https://liaoxuefeng.com/books/python/function/recursive-function/index.html)

## 什么是递归函数

函数在内部**调用自身本身**，就是递归函数。

以阶乘为例：`n! = 1 x 2 x 3 x ... x n`，可以表示为 `fact(n) = n x fact(n-1)`，只有 `n=1` 时特殊处理：

```python
def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)
```

```python
>>> fact(1)     # 1
>>> fact(5)     # 120
>>> fact(100)   # 9332621544394415268...（超大数，精确计算）
```

`fact(5)` 的计算过程：

```
=> fact(5)
=> 5 * fact(4)
=> 5 * (4 * fact(3))
=> 5 * (4 * (3 * fact(2)))
=> 5 * (4 * (3 * (2 * fact(1))))
=> 5 * (4 * (3 * (2 * 1)))
=> 5 * (4 * (3 * 2))
=> 5 * (4 * 6)
=> 5 * 24
=> 120
```

## 栈溢出

函数调用通过**栈（stack）**实现：进入函数调用栈加一层栈帧，返回则减一层。栈的大小有限，**递归次数过多会导致栈溢出**：

```python
>>> fact(1000)
RuntimeError: maximum recursion depth exceeded in comparison
```

### 尾递归

解决栈溢出的理论方法：**尾递归优化**。

尾递归指：函数返回时调用自身本身，且 `return` 语句**不能包含表达式**。做了优化的解释器会把尾递归只占用一个栈帧，不会栈溢出。

普通递归 `return n * fact(n - 1)` 含乘法表达式，不是尾递归。改写方法：把每步的乘积作为参数传入：

```python
def fact(n):
    return fact_iter(n, 1)

def fact_iter(num, product):
    if num == 1:
        return product
    return fact_iter(num - 1, num * product)
```

调用过程（栈不增长）：

```
=> fact_iter(5, 1)
=> fact_iter(4, 5)
=> fact_iter(3, 20)
=> fact_iter(2, 60)
=> fact_iter(1, 120)
=> 120
```

⚠️ 遗憾的是，**Python 解释器没有做尾递归优化**，即使改成尾递归也会栈溢出。

实测（Python 3.13，默认 `sys.getrecursionlimit() == 1000`）：`fact_iter(5000, 1)` 依然抛 `RecursionError: maximum recursion depth exceeded`。改成尾递归只是换了个写法，**栈帧照样一层层叠加**，并没有省下内存；真要算大数请用循环或 `math.factorial`。

## 补充：`fact_iter` 里的 `_iter` 是什么

`_iter` **不是语法、不是关键字，只是函数名的一部分**，用来表示"这是某个函数的迭代版"。解释器对它没有任何特殊处理，换成 `fact_loop`、`helper` 效果完全一样。

它承担的实际作用是**分工会话**：

- 对外入口 `fact(n)` 只收一个参数，调用方用起来最省事；
- 真正干活的是 `fact_iter(num, product)`，多出来的 `product` 是**累加器**——把每一步的中间结果提前算好、顺着参数传给下一次调用，这样 `return` 后面就只剩一个函数调用、没有表达式了（这正是尾递归的要求）。

三个长得很像的东西，别混：

| 写法 | 是什么 | 例子 |
| --- | --- | --- |
| `fact_iter` | 自定义函数名，`iter` 只是三个普通字母 | 本文的阶乘尾递归版 |
| `iter(x)` | **内置函数**，返回 x 的迭代器 | `it = iter([1, 2, 3])` |
| `__iter__` | 双下划线**协议方法**，定义在类里 | `for` 能遍历对象靠它 |

顺带一提：单下划线**前缀**（如 `_helper`）在模块层面约定为"内部使用，外部不要直接引用"；`fact_iter` 没有前缀下划线，它是普通公开函数。

## 练习：汉诺塔

编写 `move(n, a, b, c)`，打印把 n 个盘子从 A 借助 B 移动到 C 的步骤：

```python
def move(n, a, b, c):
    if n == 1:
        print(a, '-->', c)
        return
    move(n - 1, a, c, b)   # 先把上面n-1个从A借助C移到B
    move(1, a, b, c)       # 再把最底下的盘子从A移到C
    move(n - 1, b, a, c)   # 最后把n-1个从B借助A移到C

move(3, 'A', 'B', 'C')
```

## 小结

- 递归函数优点：逻辑简单清晰；理论上所有递归都能写成循环，但循环不如递归清晰
- 缺点：调用过深会导致栈溢出
- 尾递归和循环等价，但 Python 解释器没有尾递归优化，任何递归函数都存在栈溢出问题
- 函数名里的 `_iter` 只是命名习惯（表示迭代版），与内置函数 `iter()`、协议方法 `__iter__` 无关
