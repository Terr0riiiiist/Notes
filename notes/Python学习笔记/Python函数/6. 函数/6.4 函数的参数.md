# 函数的参数

> 来源：[廖雪峰 Python教程 - 函数的参数](https://liaoxuefeng.com/books/python/function/parameter/index.html)

Python 除必选参数外，还支持默认参数、可变参数、关键字参数、命名关键字参数，接口灵活。

## 位置参数

调用时按**位置顺序**依次赋值：

```python
def power(x, n):
    s = 1
    while n > 0:
        n = n - 1
        s = s * x
    return s

>>> power(5, 2)   # 25，5赋给x，2赋给n
>>> power(5, 3)   # 125
```

### 仅位置参数：分隔符 `/`

`/` 是**仅位置参数**的分隔符（Python 3.8+），写在它**左边**的参数只能用位置传，不能用关键字传：，写在它**左边**的参数只能用位置传，不能用关键字传：

```python
def f(a, /, b, *args, c, d=4, **kwargs):
    print(a, b, args, c, d, kwargs)

>>> f(1, b=2, c=5)      # OK：a 用位置传
>>> f(a=1, b=2, c=5)    # TypeError: got some positional-only arguments passed as keyword arguments: 'a'
```

`/` 与 `*` 是一对**对称**的设计：`/` 是"关键字到此为止"，`*` 是"关键字从这里开始"。夹在中间的 `b` 才两头都能传。

| 参数                    | 传法     |
| --------------------- | ------ |
| `a`（`/` 左侧）           | 只能位置   |
| `b`（`/` 与 `*args` 之间） | 位置或关键字 |
| `args`                | 只能位置   |
| `c`、`d`（`*args` 右侧）   | 只能关键字  |
| `kwargs`              | 只能关键字  |

为什么要用 `/`：

1. **参数名不算 API 的一部分** —— 库函数里把 `a` 改名，调用方不用动
2. **避开与 `**kwargs` 的命名冲突** —— `def f(name, /, **kwargs)`，调用方传的 `name=...` 只会进 `kwargs`，不会被形参抢走
3. **如实描述 C 函数** —— `len(obj)`、`pow(x, y, z)` 这些内建本来就是纯位置的

语法约束：`/` 必须写在 `*` 之前；可以出现在参数列表的任意切点（`def g(a, b, /, c, d)` 就是 a、b 仅位置）；写的是正斜杠 `/`。

## 默认参数

把变化小的参数设为默认值，简化调用：

```python
def power(x, n=2):     # 必选参数在前，默认参数在后
    ...

>>> power(5)      # 相当于 power(5, 2)
>>> power(5, 3)   # n>2 时必须明确传入
```

多个默认参数时可**不按顺序**提供，但必须写参数名：

```python
def enroll(name, gender, age=6, city='Beijing'):
    ...

>>> enroll('Sarah', 'F')                  # 全用默认值
>>> enroll('Bob', 'M', 7)                 # 按顺序给 age
>>> enroll('Adam', 'M', city='Tianjin')   # 不按顺序必须写参数名
```

### ⚠️ 默认参数的大坑

默认参数在**函数定义时**就被计算出来了。如果默认值是可变对象（如 list），每次调用会"记住"上次的修改：

```python
def add_end(L=[]):
    L.append('END')
    return L

>>> add_end()      # ['END']
>>> add_end()      # ['END', 'END']  ← 错了！
>>> add_end()      # ['END', 'END', 'END']
```

**定义默认参数必须指向不变对象**，用 `None` 修复：

```python
def add_end(L=None):
    if L is None:
        L = []
    L.append('END')
    return L

>>> add_end()      # ['END']
>>> add_end()      # ['END']  ← 无论调用多少次都正确
```

不变对象的好处：内部数据不可修改，减少出错；多任务环境下同时读不需要加锁。

## 可变参数

参数前加 `*`，传入个数任意（可为 0 个），函数内部收到的是一个 **tuple**：

```python
def calc(*numbers):
    sum = 0
    for n in numbers:
        sum = sum + n * n
    return sum

>>> calc(1, 2)      # 5
>>> calc()          # 0
```

已有 list/tuple 时，在前面加 `*` 把元素作为可变参数传入：

```python
>>> nums = [1, 2, 3]
>>> calc(*nums)     # 等价于 calc(1, 2, 3)
14
```

## 关键字参数

参数前加 `**`，可传入 0 个或任意个**含参数名**的参数，函数内部组装为一个 **dict**：

```python
def person(name, age, **kw):
    print('name:', name, 'age:', age, 'other:', kw)

>>> person('Michael', 30)
name: Michael age: 30 other: {}
>>> person('Bob', 35, city='Beijing')
name: Bob age: 35 other: {'city': 'Beijing'}
```

已有 dict 时，用 `**` 展开传入（注意 `kw` 是 extra 的一份**拷贝**，改动不影响原 dict）：

```python
>>> extra = {'city': 'Beijing', 'job': 'Engineer'}
>>> person('Jack', 24, **extra)
name: Jack age: 24 other: {'city': 'Beijing', 'job': 'Engineer'}
```

用途：扩展函数功能，如注册功能中必填项固定、其他都是可选项。

## 命名关键字参数

限制调用者能传入的关键字参数名。用特殊分隔符 `*`，`*` 后面的参数被视为命名关键字参数：

```python
def person(name, age, *, city, job):
    print(name, age, city, job)

>>> person('Jack', 24, city='Beijing', job='Engineer')
Jack 24 Beijing Engineer
```

- 调用时**必须传参数名**，否则报错：`person('Jack', 24, 'Beijing', 'Engineer')` → TypeError
- **如果定义中已有可变参数，后面的命名关键字参数不需要再加 `*`：**

```python
def person(name, age, *args, city, job):
    ...
```

即：**`*args` 或裸 `*` 之后的所有参数（除末尾的 `**kw`）都是命名关键字参数**，一律不能用位置传。

- **有默认值也依然是命名关键字参数**（最常踩的坑）——默认值只决定"可不可以不传"，不决定"能不能位置传"：

```python
def f(*args, mode='r'):
    ...

>>> f(1, 2, mode='w')   # OK
>>> f(1, 2, 'w')        # TypeError —— 别被默认值骗了
```

- 可以有默认值，简化调用：

```python
def person(name, age, *, city='Beijing', job):
    ...

>>> person('Jack', 24, job='Engineer')   # city用默认值
```

- **没有可变参数时必须写 `*`**，否则 `city`、`job` 会被当成位置参数

## 参数组合

5 种参数可组合使用，定义顺序必须是：

**必选参数 → 默认参数 → 可变参数 → 命名关键字参数 → 关键字参数**

```python
def f1(a, b, c=0, *args, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'args =', args, 'kw =', kw)

def f2(a, b, c=0, *, d, **kw):
    print('a =', a, 'b =', b, 'c =', c, 'd =', d, 'kw =', kw)
```

```python
>>> f1(1, 2)                        # a=1 b=2 c=0 args=() kw={}
>>> f1(1, 2, 3, 'a', 'b', x=99)     # a=1 b=2 c=3 args=('a','b') kw={'x':99}
>>> f2(1, 2, d=99, ext=None)        # a=1 b=2 c=0 d=99 kw={'ext':None}
```

对于任意函数，都可以通过 `func(*args, **kw)` 的形式调用：

```python
>>> args = (1, 2, 3, 4)
>>> kw = {'d': 99, 'x': '#'}
>>> f1(*args, **kw)
a = 1 b = 2 c = 3 args = (4,) kw = {'d': 99, 'x': '#'}
```

> 提示：不要同时使用太多参数组合，否则接口可理解性很差。

## 小结

- 默认参数一定要用**不可变对象**，否则会有逻辑错误
- `*args` 是可变参数，args 接收 tuple；`**kw` 是关键字参数，kw 接收 dict
- 调用时可先组装 list/tuple 再 `func(*args)`，或组装 dict 再 `func(**kw)`
- `*args`、`**kw` 是 Python 习惯写法，最好遵循
- 命名关键字参数用于限制参数名，没有可变参数时别忘了分隔符 `*`
- `*args` 或 `*` 之后的参数**一律**是命名关键字参数，带默认值也不例外
- `/`（3.8+）左侧是**仅位置参数**，不能用关键字传；与 `*` 对称——`/` 管左边，`*` 管右边
- 完整顺序：`仅位置 / 位置或关键字 / *args / 命名关键字 / **kw`，`**kw` 永远只能放最后
