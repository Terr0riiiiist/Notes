### 1.自增自减运算符++/--
i.e. a=0;
*前置： a++;    **a = a +1**    前置先使用再自增
后置:   后置先自增再使用




``` **int a =5**
 int a =5
   int b = ++a
   a先变成6，然后b=a=6
```

### 异或运算符 ^
true ^ true ---> false
false ^ false ---> false
true ^ false ---> true
false ^ true ---> true
即：两个布尔值不相同，才输出true;否则输出false
