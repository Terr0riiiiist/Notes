### Resizable Array
- Think about a set of functions that provide a mechanism of resizable array of int.
	- Growable
	- Get the current size
	- Access to the elements

### Interface
- Array array_create(int init_size)
```c
typedef struct{
	int *array;
	int size;
} Array;

Array array_create(int init_size) {
	Array a;   //在函数外定义的typedef 结构体array
	a.array = (int*)malloc(sizeof(int)*init_size);  // malloc申请到的内存起始地址(void*)
	a.size  = init_size;
	return a;
}
```
---

- void array_free(Array \*a);
```C
void array_free(Array *a){
	free(a->array);
	a->array = NULL;
	a->size = 0;
}
```
- a->array: 内存释放了，但是指针仍指向那一块旧地址；释放悬空指针防止内存泄漏
- a->size : 保持程序一致性，“逻辑”清零
----

- int array_size(const Array \*a);
```c
int array_size(const Array *a){
	if (a == NULL){
		return 0;
	}
	return a->size;
}
```
---

- int\* array_at(Array \*a, int index);
```c
int* array_at(Array *a, int index{
	assert(a != NULL);
	assert(a->array != NULL);
	assert(a > 0 && a < a->size);
	return &(a->array[index])
	}	
```

---

- void array_inflate(Array \*a, int more_size);
```c
void array_inflate(Array *a, int more_size){
	a->size += more_size;
	a->array = (int*)realloc(a->array, sizeof(int) * a->size) 
	}
```
*没有加入内存申请是否成功的检查*
