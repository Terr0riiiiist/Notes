### 运算符&
获取变量的地址，操作数必须是变量

*&不能对没有地址的东西取地址*
- &(a+b);
- &(a++);


*对数组取地址：*

```c
#include <stdio.h>

int main（void){
 int a[10];
 
 printf("%p\n",&a);
 printf("%p\n",a);
 printf("%p\n",&a[0]);
 printf("%p\n",&a[1]);
 
 return 0;
}
```
---------- output ----------

000000F29E2FF810
000000F29E2FF810
000000F29E2FF810
000000F29E2FF814

**对数组a直接取地址,&a , a[0]结果相同 ;  a[1]和a[0]差了4个字节，即一个int**
