
- 函数返回运算的状态，结果通过指针返回
- 常用的套路是让函数返回特殊的不属于有效范围内的值来表示出错
- -1或0（在文件操作会看到大量的例子）
- 但是当任何数值都是有效的可能结果时，就得分开返回了

```C
#include <stdio.h>

/**
 * @return 如果除法成功，返回1；否则返回0
 */
int divide(int a, int b, int *result);

int main(void)
{
    int a = 5;
    int b = 2;
    int c;
    if ( divide(a, b, &c) ) {
        printf("%d/%d=%d\n", a, b, c);
    }
    return 0;
}

int divide(int a, int b, int *result)
{
    int ret = 1;
    if ( b == 0 ) ret = 0;
    else {
        *result = a/b;
    }
    return ret;
}
```


**注意定义指针变量必须要先指向一个 实际的变量再使用
```
int *p = 0;   ---->定义指针变量，指向内存地址0
*p = 12;   ---->往0写入12
printf("*p=%d",*p)  --->地址 `0` 是操作系统保留的受保护内存，程序**绝对没有权限**去读写它。因此，运行到这一行时，程序会直接报错崩溃，报出“段错误”（Segmentation Fault）。
```
