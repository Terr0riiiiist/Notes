- 内存中有0地址，但是0地址通常是不能随便碰的地址
- 指针不应该具有0值
- 可以用0地址来表示特殊的事情：
	- 返回的指针是无效的
	- 指针没有被真正初始化（先初始化为0）
- **NULL**是一个预定定义的符号，表示0地址
- 需要初始化时最好用**NULL**


### 指针的类型
- 无论指向什么类型，所有的指针大小都相同，因为都是地址
- 但是指向不同类型的指针是不能直接互相赋值的，目的是避免用错指针

#### 指针的类型转换
- void* 表示不知道指向什么东西的指针
	- 计算时与char\*相同（但不相通）
- 指针也可以转换类型
	- int \*p = &i; void\*q = (void*) p;

#### 指针的用途
- 传入较大数据时作参数
- 传入数组后对数组做操作
- 函数返回不止有一个结果
	- 用函数修改不止一个结果
- 动态申请内存
