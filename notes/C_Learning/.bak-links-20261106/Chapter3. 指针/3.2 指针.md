### 指针就是保存地址的变量
- *变量的值是内存地址*
- *指针变量的值是具有实际值的变量的地址

	```c
	*有两种含义
	int *p;          // 这里是修饰符，说明 p 是一个指向 int 的指针变量
    void f(int *p);  // 这里是修饰符，说明形参 p 是一个整型指针[cite: 1]
    char *str;       // 这里是修饰符，说明 str 是一个字符指针
    
    
     *p = 26;         // 运算符：顺着 p 找到对应的内存，把 26 赋进去[cite: 1]
     int x = *p;      // 运算符：顺着 p 找到对应的内存，把里面的值取出来赋给 x
     printf("%d", *p);// 运算符：顺着 p 找到对应的内存，打印出里面的值[cite: 1]
	```
   *   * 1.作为变量的类型修饰符
       **定义变量或者声明函数的参数，此时只是一个标志，不进行任何内存操作
   -    * 2.作为解引用运算符
    ** 在**可执行代码（表达式）**中，对一个**已经存在的指针变量**进行操作时

```c
void f(int *p);
void g(int k);

int main(void)
{
    int i = 6;
    printf("&i=%p\n", &i);
    f(&i);
    g(i);

    return 0;
}

void f(int *p)   ---> 变量的类型修饰符，表示这个函数的参数是指针类型需要传入变量的地址
{
    printf(" p=%p\n", p);
    printf("*p=%d\n", *p);
    *p = 26;  ------>对指针变量p解引用，此时*p整体可以看作一个int
}

void g(int k)
{
    printf("k=%d\n", k);
}
```
