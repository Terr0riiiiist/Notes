**定义数组 ：类型 变量名称 [元素数量]
- int grades[100];
- double weight[20];

**特性：
1.所有元素具有相同数据类型
2.一旦创建不能改变大小
3.*数组中的元素在内存中是连续依次排列*


使用数组时放在][]中的数字叫做下标或索引(index),从0开始计数;
- grades[0]
- average[5]

#### 编译器和运行环境都不会检查下标是否越界
- **segmentation fault

```C
const int number = 10;
int x;
int count[number];
int i;

for(i=0; i<number; i++){
	count[i] = 0;
}
scanf("%d".&x);
while (x!= -1){
	if (x>=0 && x <=9) count[x]++;
	scanf("%d",&x);
}
for(i=0; i<number; i++){
	printf("%d:%d\n", i, count[i]);
}
```
