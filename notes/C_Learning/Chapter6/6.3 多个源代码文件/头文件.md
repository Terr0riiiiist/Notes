- 把函数原型放在一个头文件(.h 结尾)中，在需要调用这个函数的源代码文件中 #Include 这个头文件，就能让编译器在编译的时候知道函数的原型

- 在使用和定义这个函数的地方都应该 #include 这个头文件
- 任何.c 都有对应的同名.h, 把所有对外公开的函数原型和全局变量声明放进去

### include
- #include 是一个编译预处理指令，和宏一样，在编译之前就处理了
- 把那个文件的全部文本内容原封不动插入到其坐在的地方
	- 不一定要在.c文件的最前面 #include

- "" 要求编译器首先在当前目录寻找这个文件，如果没有就到编译器指定目录找
- <>让编译器只在指定的目录找


#### 误区
- #include 不是用来引入库的
- stdio.h里只有printf的**原型**, printf 代码在另外地方
- C语言编译器会默认引入所有标准库
-  #include <stdio.h> 只是为了让编译器知道printf函数的原型，保证你调用时给出的参数值是正确的类型

### 不对外公开的函数
- 在函数前加上**static** 就使得它成为只能在所在编译单元中被使用的函数
- 在全局变量前加上**static**就是的它成为智能在所在的编译单元中被使用的全局变量
