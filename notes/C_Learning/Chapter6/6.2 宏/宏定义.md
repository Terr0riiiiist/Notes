- \# 开头的是编译预处理指令
- 不是C语言的成分
- \#define 用来定义一个宏


### define
- **define  name value
	- 注意没有结尾的分号，因为不是C的语句
	- 名字必须是一个单词，值可以是各种东西
	- 在编译器开始编译之前，编译预处理程序会把程序中的名字换成值
	- 完全的文本替换

### 宏(Macro)
- 如果一个宏的值中有其他的宏名字，也会被替换
- 如果一个宏的值超过一行，最后一行之前的行末需要加\
- 宏的值后面出现的注释不会被当作宏的值的一部分

### 没有定义的宏
- \#define _DEBUG
- 用于条件编译，后面有其他的编译预处理指令来检查这个宏是否已被定义过

```c
#define _DEBUG
#include <stdio.h>
int main() {
    int x = 10;
    // 条件编译检查：如果定义了 _DEBUG，这部分代码就会被编译进程序
    #ifdef _DEBUG
        printf("Debug mode: x = %d\n", x);
    #endif
    // ... 其他正式逻辑
    return 0;
}
```
