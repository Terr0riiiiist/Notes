### 结构作为函数参数
```c
int numberOfDays(struct date d)
```
- 整个结构可以作为参数的值传入函数
- 表示在函数内新建一个结构变量，并复制调用者结构的值
- 也可以return一个结构
- 与数组完全不同

```c
#include <stdio.h>
#include <stdbool.h>

struct date{
    int date;
    int month;
    int year;
};

bool isLeap(struct date );
int numberOfDays(struct date );

int main(void){
    struct date today, tomorrow;
    printf("Enter today: mm dd yyyy");
    scanf("%d  %d  %d",&today.month, &today.date, &today.year);
    tomorrow = today;
    if(today.date + 1 > numberOfDays(today)){
        if(today.month != 12){
            tomorrow.month = today.month+1;
        } else {
            tomorrow.month = 1;
            tomorrow.year  = today.year + 1;
        }
        tomorrow.date = 1;
    } else {
        tomorrow.date = today.date + 1;
    }

    printf("tomorrow date: %d - %d - %d\n",tomorrow.month, tomorrow.date, tomorrow.year);
    return 0;
}
int numberOfDays(struct date d){
    const int daysPerMonth[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
    int days = daysPerMonth[d.month];
    if(isLeap(d) && d.month == 2 ){
        days++;
    }
    return days;
}

bool isLeap(struct date d){
    bool leap = false;
    if((d.year % 4 == 0 && d.year % 100 != 0) ||d.year % 400 == 0){
        leap = true;
    }
    return leap;
}

```

### 结构指针
- 和数组不同，结构变量的名字并不是结构变量的地址，必须使用&运算符
- struct date \*pDate = &today;

通过结构指针访问结构体变量:
```c
struct point{
	int x1;
	int x2;
}
struct point *p*
p-> x1  = 20;
(*p).x1 = 20;
```
**数组的指针类型是 int,所以可以通过p+1访问下一个成员变量;
结构的指针类型是struct point,p+1访问的是当前位置+sizeof(struct point),会跳出结构体越界，不能用p+1访问下一个成员变量,只能用 p -> x2访问。

修改结构变量：
```c
void func(struct point *p);
```
