- **枚举(Enumeration)是一种用户定义的数据类型，用关键字*enum*以如下语法来声明:

```c
enum 枚举类型名字 {name1,name2,name3,..}
```

- 枚举类型名字通常并不真的使用，要用的是{}里的名字,它们是常量符号，类型是int,值依次从0到n.
```c
enum colors{red,yellow,green};
```
---> 创建了3个常量 : enum colors red , yellow, green = 0,1,2


*实际上枚举类型是以int做内部计算和外部输入输出的*

### technique :枚举的自动计数
```c
#include <stdio.h>

enum COLOR {RED, YELLOW, GREEN, NumCOLORS};

int main(int argc, char const *argv[])
{
    int color = -1;
    char *ColorNames[NumCOLORS] = {
        "red", "yellow", "green",
    };
    char *colorName = NULL;

    printf("输入你喜欢的颜色的代码: ");
    scanf("%d", &color);

    if ( color >=0 && color < NumCOLORS ) {
        colorName = ColorNames[color];
    } else {
        colorName= "unknown";
    }

    printf("你喜欢的颜色是%s\n", colorName);

    return 0;
}
```
NumsCOLORS就是枚举的颜色数量; 需要遍历的时候就取枚举的最后一个值

### 枚举量
- 声明枚举量的时候可以指定值
	```c
	enum COLOR{RED=1, YELLOW, GREEN = 5};
	```
