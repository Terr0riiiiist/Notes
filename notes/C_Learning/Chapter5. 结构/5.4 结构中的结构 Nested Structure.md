*表示一个矩形: 通过左上和右下两个点定义一个矩形*
```c
struct point{
	int x;
	int y;
}
struct rectangle{
	struct point pt1;
	struct point pt2;
} A
//共有四个成员变量: A.pt1.x,A.pt1.y,A.pt2.x,A.pt2.y
```
访问pt1.x的几种方式:
```c
struct rectangle A,*rp;
r.pt1.x
rp ->pt1.x
(r.pt1).x
(rp->pt1).x
```
