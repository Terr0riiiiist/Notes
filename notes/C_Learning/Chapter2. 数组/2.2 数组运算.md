**求一个数组元素的个数：**
```c
sizeof(a) / sizeof(a[0])
```
*不需要遍历数组就能知道数组长度*

```C
#include <stdio.h>

int main() {

  const int number = 1000;
  int prime[1000];
  for (int i = 0; i < number; i++) {
    prime[i] = 1;
  }
  for (int x = 2; x < number; x++) {
    if (prime[x]) {
      for (int i = 2; i * x < number; i++) {
        prime[i * x] = 0;
      }
    }
  }

  for (int i = 2; i < number; i++) {
    if (prime[i] == 1)
      printf("%d\t ", i);
  }
}

```
