C语言的字符串:

```c
char word[] = {'H','e','l','l','o','!','\0'}
// 共有7格单元
```

- 以0结尾的一串字符
	- 0或'\0'是一样的，但不是'0'
- 0标志字符串的结束，但不是字符串的一部分
	- 计算字符串长的的时候不包含这个0
- 字符串以数组的形式存在，以数组或指针的形式访问（更多以指针形式）
- *string.h*里有很多处理字符串的函数
- 两个相邻的字符串常量会被自动连接起来

### 字符串常量
- “Hello" 会被编译器变成一个字符数组放在某处，这个数组长度是6；结尾有表示结束的0
- C语言字符串是以字符数组的形态存在的
	- 不能用运算符对字符串做运算
	- 通过数组的方式可以便利字符串
- 可以用双引号的方式来初始化字符串
```c
printf("123""456");
-----> 123456
```
