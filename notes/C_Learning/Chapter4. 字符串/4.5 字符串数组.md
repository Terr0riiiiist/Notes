char \*\*a :  指向另一个指向字符串的指针
```c
#include <stdio.h>
int main(void) {
    char *str = "Hello";
    char **a = &str;

    printf("%s\n", *a);
    printf("%c\n", **a);

    return 0;
}
// Hello
// H
```

char a\[\]\[10\] : 有一个a\[\]数组，其中每一个都是10长度

### 程序参数
- int main(int argc, char const \*argv\[\])
- argv\[0\]是命令本身
