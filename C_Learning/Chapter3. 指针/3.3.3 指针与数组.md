- *函数参数表中的数组实际上是指针*
- sizeof(a)  ==  sizeof(int*)
- **可以用数组运算符[]进行运算
- 
```c
- 以下四种函数原型是等价的：
  - `int sum(int *ar, int n);`
  - `int sum(int *, int);`
  - `int sum(int ar[], int n);`
  - `int sum(int [], int);`
```


### 数组变量是特殊的指针
-*数组变量本身表达地址 ---->
 - int a[10]; int *p = a; 无需用&取地址
 - 数组的单元表达的是变量，需要用&取地址
 - a == &[0]
 -[]运算符可以对数组做，也可以对指针做：
 - p[0]    a[0]
 -* 运算符可以对指针做，也可以对数组做
  - *a  = 25；
