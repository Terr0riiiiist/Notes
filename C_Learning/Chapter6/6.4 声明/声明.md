- int i; 是变量的**定义**
- extern int i; 是变量的**声明**

**声明是不产生代码的东西**
- 函数原型
- 变量声明
- 结构声明
- 宏声明
- 枚举声明
- 类型声明
- inline函数
**定义是产生代码的东西

*只有声明可以被放在头文件中

### 标准头文件结构
```c
#ifndef _LIST_HEAD_
#define _LIST_HEAD_

#include "node.h"

typedef struct _list {
	Node* head;
	Node* tail;
} List;

#endif
```
- 运行条件编译和宏，保证在一个编译单元中只会被#include 一次
- \#pragma  once
