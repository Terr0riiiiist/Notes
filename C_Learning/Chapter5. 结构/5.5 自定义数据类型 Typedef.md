### typedef
```c
typedef int Length
```

**使得*Length*成为*int*类型的别名
- 这样，***Length***就可以替代int 出现在变量定义和参数声明的地方
- Length a, b, len;
- Length numbers[10];

```c
typedef long int64_t
typedef struct ADate {
	int month;
	int day;
	int year;
} Date;

int64_t i =1000000;
Date d = {9, 1, 2005};  ---> 简化了复杂的名字(struct ADate d)
```
