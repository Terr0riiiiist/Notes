### printf
```c
%[flags][width][.prec][hIL]
```

|**Flag**|**含义**|
|---|---|
|-|左对齐|
|+|在前面放 + 或 -|
|(space)|正数留空|
|0|0填充|
#### flags
```c
// 宽度设为 6，默认右对齐
printf("[%6d]\n", 123);   // 输出: [   123]

// 加上 - 号，改为左对齐
printf("[%-6d]\n", 123);  // 输出: [123   ]

printf("%d\n", 123);    // 输出: 123  （正数无符号）
printf("%+d\n", 123);   // 输出: +123 （强制显示 +）
printf("%+d\n", -123);  // 输出: -123 （负数照常显示 -）

printf("% d\n", 123);   // 输出:  123 （前面多了一个空格）
printf("% d\n", -123);  // 输出: -123

printf("%5d\n", 5);   // 默认宽度为 5，前面补空格 -> 输出: [    5]
printf("%05d\n", 5);  // 加上 0 标志，宽度不够时前面补 0 -> 输出: [00005]]

```
#### width

|**width 或 prec**|**含义**|
|---|---|
|`number`|最小字符数|
|`*`|下一个参数是字符数|
|`.number`|小数点后的位数|
|`.*`|下一个参数是小数点后的位数|
```c
printf("%5d\n", 42);   // 指定宽度为 5
// 输出: [   42] （前面补了 3 个空格）

printf("%*d\n", 6, 42);  // 第一个参数 6 代表宽度，第二个参数 42 是要打印的数
// 输出: [    42]

printf("%.2f\n", 3.14159);  // 保留 2 位小数
// 输出: 3.14

printf("%.*f\n", 3, 3.14159);  // 第一个参数 3 代表保留 3 位小数
// 输出: 3.142
```

### hIL (作为类型输出)

|**类型修饰**|**含义**|
|---|---|
|`hh`|单个字节|
|`h`|short|
|`l`|long|
|`ll`|long long|
|`L`|long double|

|**type**|**用于**|**type**|**用于**|
|---|---|---|---|
|`i 或 d`|`int`|`g`|`float`|
|`u`|`unsigned int`|`G`|`float`|
|`o`|八进制|`a 或 A`|十六进制浮点|
|`x`|十六进制|`c`|`char`|
|`X`|字母大写的十六进制|`s`|字符串|
|`f 或 F`|`float`, 6|`p`|指针|
|`e 或 E`|指数|`n`|读入/写出的个数|
```c
int main(void) {
    int num ;
    printf("%dty%n\n", 12345, &num);
    printf("num = %d\n", num);
    return 0; 
}
```
输出: 12345ty
	  7

* *%n不会输出结果，而是将此前已经**输出的字符数量**写入对应的整数指针所指向的内存
