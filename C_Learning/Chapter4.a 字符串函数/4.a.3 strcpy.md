```c
char *strcpy(char *restrict dst, const char *restrict src);  //dst:destination
```

- 把**src的字符串拷贝到**dst
	- **restrict** : **src,**dst不重叠
- 返回**dst,为了让strcpy 参与运算




```c
#include <stdio.h>
char* mycpy(char *dst, const char*src){
    char *p = dst;
    while(*src != '\0'){
        *dst = *src;
        dst++;
        src++;
    }
    *dst = '\0';
    return p;
}
```
*其中while可以精简为下面的一行：*
```c
char* mycpy(char* dst, const char* src){
    char* ret = dst;
    while ( *dst++ = *src++ ) ;
    return ret;
    }

```

### **  \*dst++ =  \* src++
- 先取dst和src当前的值
- 赋值
- dst++, src++

**C语言中赋值表达式的结果是用于赋值的值，所以 \*dst++ = \*src++ 表达式结果是src
while (\*dst++  == \* src++)  包含了\*src != '\0'
