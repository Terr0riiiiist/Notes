###  字符串中找字符
```C
char* strchr(const char *s, intc); //从左向右寻找
char* strrchr(const char* s, intc); //从右向左寻找
```
- *返回NULL表示没有找到*

```c
int main(void){
char s[] = "Hello";
char *p = strchr(s,'l')
p = strchr(p+1,'l');  //寻找第二个l
printf("%s\n",p);

return 0;
}
```

*如果我想拷贝指针p之前的字符串：*
```c
char s[] = "Hello";
char *p = strchr(s,'l');
char c = *p;  ---->先创建一个临时变量存储*p的值
*p = '\0'; --->字符串s到这里为止
char *t = (char*)malloc(strlen(s)+1);
strcpy(t,s);
printf("%s\n",t);
*p = *c;
free(t);

```
